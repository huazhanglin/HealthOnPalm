# W6-T7 商店截图拍摄清单

GitHub / Pages 不通时仍可先拍好图，存本地，GitHub 通了再上传 Connect。

本机说明书里的旧图（`doc/manual-assets/`）**不要直接上传**：界面文案仍是旧品牌（Health On Palm / 掌上健康），且尺寸未必符合 2026 Connect。请用 **1.0.0** 真机或 TestFlight 包重拍。

---

## 1. 尺寸（2026）

| 优先级 | Connect 显示类 | 竖图像素（任选其一） | 建议机型 |
|--------|----------------|----------------------|----------|
| **必传** | iPhone **6.9"** | **1320×2868**（优先）或 1290×2796 或 1260×2736 | 16/17 Pro Max；15 Pro Max 拍出 1290×2796 也可 |
| 可选 | iPhone 6.3" | 1206×2622 或 1179×2556 | 15/16/17 Pro；不传则由 6.9" 自动缩放 |

- 格式：PNG 或 JPEG，**无透明**
- 竖图即可；本周不做 iPad / 预览视频
- 系统截图：侧键 + 音量上（或控制中心截屏）

若只有一台 6.1"/6.3" 手机：先拍一套，用预览工具导出成 **1320×2868**（加黑边或等比放到画布）再上传到 6.9" 槽位。不要把错误像素硬塞进 Connect。

## 2. 五张图顺序（中文 UI）

| # | 画面 | 怎么摆 | 验收 |
|---|------|--------|------|
| 1 | **首页** | 晨报 + 恢复分可见；「HealthKit 已连接」更好；可有步数 | 无「内测」「DEBUG」；无疗效大字 |
| 2 | **训练** | 今日计划列表，能看见 **组 × 次数** 或 **组 × 秒** | 不要空白「正在生成」 |
| 3 | **助手** | 至少一轮用户问 + HOP 答（生活方式类，非处方） | 欢迎语可用，但最好有真实问答 |
| 4 | **记录** | 运动 / 睡眠 / 心情入口页 | 标题「健康记录」即可 |
| 5 | **我的** 或 **健康授权** | 「我的」见档案 + 数据同步已授权；或授权页说明只读 | 页底「删除账号」**不必**入镜（避免审核员误点） |

不要：医疗十字、心电图诊断风、保证降压/治愈的文案。状态栏可保留。

---

## 3. 拍摄前准备（审核号或自用号均可）

1. 装 **1.0.0 / 140**（自定义基座可先拍；最终以 TestFlight 商店包再对一眼）。  
2. 完成引导，授权 Apple「健康」。  
3. 首页有恢复分；训练页已生成今日计划。  
4. 助手里问一句无害问题，例如：「今天恢复分一般，晚上怎么安排比较轻松？」  
5. 记录页保持默认入口即可。  
6. 检查顶栏 / 文案：中文名 **掌握健康**，不要出现旧称「掌上健康」。
