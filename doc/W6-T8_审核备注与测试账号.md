# W6-T8 审核备注与测试账号

不依赖 GitHub。提交审核时，把下面英文 Notes 粘进 App Store Connect → 1.0.0 → **App 审核信息 → 备注**。

**不要把真实审核密码写进 Git 仓库。** 密码只放在 Connect 和你自己的密码管理器。

---

## 1. 准备审核专用账号（现在就可以做）

用一个**新邮箱**注册（不要用你日常开发号）：

1. 打开 App（1.0.0）→ 注册 → 完成新手引导。  
2. 授权 Apple「健康」（只读）。  
3. 打开首页，确认有恢复分 / 晨报（可有「睡眠缺失」提示）。  
4. 打开「训练」，等到今日计划出现（能看到组数）。  
5. 助手里问一句生活方式问题，等回复。  
6. 「记录」里可选记一条心情或运动。  
7. 「我的」滑到底，确认能看见「删除账号」（**不要**在这个账号上点删除，除非另备一个可丢账号）。  
8. 登录页点开《隐私政策》《用户协议》，确认不再是「开发中」。

把邮箱和密码记在密码管理器；提交时填进 Notes。

若审核员拒绝 HealthKit：App 仍可手动记运动 / 睡眠 / 心情并使用助手；简报会提示数据不足。Notes 里已写明。
